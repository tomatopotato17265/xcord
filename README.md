# xcord
Discord Rich Presence for Xcode, fully made in Swift

## Assets
These must match the keys in [`xcord/AssetMap.swift`](xcord/AssetMap.swift):

| Asset name          | Used for                          |
|----------------------|------------------------------------|
| `xcode-icon`          | Generic fallback + small badge icon |
| `swift`                | `.swift`                          |
| `objc`                 | `.m`                              |
| `objcpp`                | `.mm`                             |
| `header`                | `.h`, `.hpp`                      |
| `c`                     | `.c`                              |
| `cpp`                   | `.cpp`, `.cc`                     |
| `storyboard`            | `.storyboard`                     |
| `interface-builder`     | `.xib`                            |
| `plist`                 | `.plist`, `.entitlements`         |
| `markdown`              | `.md`, `.markdown`                |
| `json`                  | `.json`                           |
| `yaml`                  | `.yml`, `.yaml`                   |
| `metal`                 | `.metal`                          |
| `shell`                 | `.sh`                             |
| `python`                | `.py`                             |
| `ruby`                  | `.rb`                             |
| `assets`                | `.xcassets`                       |
